# 🎯 Методологія пошуку донорів і партнерів для Вилоцької громади

> Документ робочий: це не теорія, а протокол дій. Бот під нього буде дописаний
> окремим етапом (розділ 12). Поки що все виконується вручну за цим порядком.

---

## 1. Вихідні дані

| Параметр | Значення | Що це дає в пошуку донорів |
|---|---|---|
| Громада | Вилоцька селищна, Берегівський р-н, Закарпаття | немає «фронтового» аргументу → робимо ставку на інші аргументи |
| Центр | смт Вилок (*Tiszaújlak*) | упізнавана угорська назва — пошук угорською дає результати |

| Етнічний склад Вилка | ≈79 % угорців | **мовно-культурний місток**, якого немає в 95 % громад України |
| Географія | кордон з Угорщиною, пункт пропуску Вилок–Тисабеч, річка Тиса | найдешевша логістика в Україні: донор із Угорщини — 1 день дороги |
| Пріоритет потреб | **1) техніка для ТПВ, 2) освітній напрям** | два різні набори донорів, два різні листи |
| Наявні побратими | немає | завдання №1 — оформити перше партнерство |
| Листування | готує бот, громада підписує і надсилає | потрібні шаблони під кожен тип донора + реєстр контактів |

**Мета на 12 місяців (вимірювана):**
1. Підписане перше побратимство (мінімум одне, бажано два: Угорщина + «друга» країна ЄС).
2. Отримано техніку для ТПВ: сміттєвоз (1 од.) та/або контейнери (50+ од.).
3. Один освітній проєкт з партнером: обладнання для школи або шкільний обмін/Erasmus+.
4. Реєстр донорів — 120 опрацьованих контактів, з них 40 листів, 8 відповідей.

## 2. Чотири принципи, на яких тримається весь пошук

1. **«Дав сусідові — дасть і нам».** Найкращий донор — той, хто вже передав техніку
   українській громаді. У нього є досвід розмитнення, транспортна схема і
   внутрішнє рішення ради. Холодний донор коштує в 5–10 разів більше зусиль.
2. **Техніка належить не меру, а оператору.** Сміттєвоз у Німеччині списує не
   ратуша, а `Abfallwirtschaftsbetrieb` / `Zweckverband` / `Landkreis`; пожежне
   авто — `Freiwillige Feuerwehr` чи угорське `Önkéntes Tűzoltó Egyesület`.
   Лист меру без копії оператору губиться. **Пишемо двом адресатам одночасно.**
   *Кейс:* сміттєвоз Mercedes для Володимира організував не мер Цвікау, а
   директор КП з управління відходами округу Хемніц.
3. **Проси конкретику, а не «допоможіть».** «Сміттєвоз із заднім завантаженням,
   1 од., обслуговує 11 сіл і 14 800 людей; наявний ГАЗ 1991 р.» — працює.
   «Потребуємо підтримки комунальної сфери» — не працює ніколи.
4. **Звіт — це інвестиція в наступну передачу.** Фото техніки в роботі, новина,
   подяка з тегом донора. Донори передають повторно саме тим, хто відзвітував.

### Коло 5. Освітні донори (другий пріоритет громади)
- **Erasmus+ KA210 / KA220** — малі партнерства шкіл: подається школа, а не КП;
  потрібен партнер в ЄС (шукається через eTwinning / European School Education Platform).

- Угорськомовні школи громади — окремий аргумент для угорських фондів;
  українська школа — для фондів ЄС і діаспори.

## 5. Скоринг донора: кому писати першим

Для кожного знайденого донора рахуємо 4 параметри (0–3 бали):

| Критерій | Що оцінюємо | 0 | 3 |
|---|---|---|---|
| **Д** Доведеність | чи вже передавав техніку/допомогу в Україну | ніколи | за останні 12 міс. |
| **М** Місток | чим ми йому «свої» | нічого спільного | угорська мова / спільна конфесія / сусід по кордону / діаспора |
| **З** Збіг потреби | чи віддає саме те, що треба (ТПВ, освіта) | інший профіль | точно наш тип |
| **В** Вартість входу *(віднімається)* | логістика, відстань, митні складнощі | >1500 км, складна схема | <300 км, є готовий маршрут |

**Пріоритет = Д + М + З − В** (максимум 9).

| Бал | Дія |
|---|---|
| **7–9** | «Гарячий» — лист цього тижня, персональний, із посиланням на їхній попередній вчинок |
| **4–6** | «Теплий» — лист після гарячих; спершу шукаємо спільного знайомого/посередника |
| **1–3** | «Холодний» — у реєстр, лист лише в масовій розсилці двічі на рік |
| **≤0** | Відсіюємо, щоб не витрачати час |

## 7. Пошуковий протокол (як знаходити ліди щотижня)

### 7.1 Мовні запити
Пошук ведемо **шістьма мовами**; формулювання підбираємо під те, як про це
пишуть місцеві ЗМІ (саме там з'являється ім'я донора).

| Мова | Приклади запитів |
|---|---|
| укр. | `громада отримала сміттєвоз від партнерів`, `передали комунальну техніку громаді Закарпаття`, `контейнери для сміття передали громаді` |
| **угор.** | `kukásautó adomány Ukrajna`, `testvértelepülés Kárpátalja adomány`, `segélyszállítmány önkormányzat Kárpátalja`, `tűzoltóautó adomány kárpátaljai település`, `iskola testvériskola Kárpátalja` |
| нім. | `Müllfahrzeug Ukraine gespendet`, `Abfallwirtschaft Landkreis Ukraine Hilfe`, `Partnerstadt Ukraine Fahrzeuge`, `Hilfstransport Kommune Ukraine` |
| пол. | `śmieciarka przekazana ukraińskiej gminie`, `gmina partnerska Ukraina sprzęt komunalny` |
| нідерл. | `vuilniswagen gedoneerd Oekraïne gemeente`, `gemeente schenkt materieel Oekraïne` |
| швед. | `sopbil donation Ukraina kommun`, `vänort Ukraina utrustning` |

Корисні оператори: `site:` (пошук по сайтах самоврядувань), лапки для точної
фрази, `when:` для свіжих новин, мінус-слова для відсіву реклами.

### 7.2 Реєстри та бази (де донори лежать списком)
1. **Cities4Cities | United4Ukraine** — профіль громади + запит на техніку.
2. **decentralization.gov.ua/twincities** — державний каталог запитів і пропозицій.
3. Списки `testvérvárosok` / `Partnerstädte` на сторінках угорських і німецьких міст.
4. Бази проєктів **HUSKROUA / Interreg** — видно, хто вже працював з Україною.
5. **eTwinning / European School Education Platform** — пошук шкіл-партнерів.
6. АМУ, ВАОТГ, Асоціація прифронтових міст — розподіл донорської техніки.

### 7.3 «Слід сусіда»
Окремий щотижневий перегляд новин громад Закарпаття про отриману техніку.
Кожна така новина = новий донор у реєстр, бо маршрут уже прокладено через ваш кордон.

### 7.4 Регіональний контекст як аргумент
На Закарпатті діє підтримана ЄС робота над **кластерними концепціями управління
відходами** (приклад — Ужгородський кластер, EuropeAid). Участь громади в
кластері різко підвищує шанси на обладнання від великих донорів (ЄС, ЄБРР,
NEFCO), бо вони фінансують не окрему громаду, а кластер. **Дія:** з'ясувати в
ОДА/департаменті екології, до якого кластера віднесено Вилоцьку громаду, і
офіційно зафіксувати в ньому свої потреби.

## 8. Воронка і робочий ритм

```
200 лідів (новини, реєстри)
   ↓ скоринг ≥4
 60 карток донорів
   ↓ пошук контактів
 40 листів
   ↓ конверсія 15–25 %
  8 відповідей
   ↓
  3 перемовини → 1–2 передачі техніки / 1 побратимство
```

**Тижневий цикл (≈3 години):**
| День | Дія |
|---|---|
| Пн | перегляд вкладки 🤝 в радарі + «слід сусіда» → 5–10 нових карток |
| Вт | пошук контактів (сайт установи → `Impressum` / `Kapcsolat` / `Kontakt`) |
| Ср | бот готує листи → голова підписує → надсилаємо 8–10 листів |
| Чт | follow-up тим, кому писали 3 тижні тому (друге нагадування — через 6 тижнів) |
| Пт | оновлення реєстру, звіти по вже отриманій допомозі, публікація подяк |

**KPI:** 10 нових карток/тиждень, 8 листів/тиждень, ≥15 % відповідей,
час відповіді на вхідний лист — до 24 годин.

## 12. Що з цього вже робить бот (реалізовано)

| Пункт методології | Команда / місце в боті |
|---|---|
| Пошук лідів сімома мовами | джерела `gnews_twin_ua/en/de/pl/hu/nl/sv` у `config/sources.yaml` |
| «Слід сусіда» по Закарпаттю | джерело `gnews_zakarpattia` |
| Відсів локального шуму | `screening.UKR_CONTEXT` — іншомовна новина має стосуватися України |
| Вкладка 🤝 з послабленими правилами | `screening.is_aid()`, `feed='aid'` |
| Окремий освітній розділ | `screening.is_edu()`, вкладка 🎓 `feed='edu'` |
| Картка донора (розділ 6) | таблиця `donors` у БД, `donors.card_from_item()` |
| Скоринг Д + М + З − В (розділ 5) | `donors.score_donor()` — ваги в `BRIDGE`, `NEED_SCORE`, `ENTRY_COST` |
| Кола близькості 1–5 (розділ 3) | `donors.detect_circle()` |
| Тип організації-донора (розділ 4) | `donors.detect_org_type()` — самоврядування, оператор відходів, пожежні, фонд, парафія, школа |
| Листи 5 мовами (розділ 10) | `donors.build_letter()`, шаблони `LETTERS`, паспорт громади — `config/profile.yaml` → `community` |
| Воронка і нагадування (розділ 8) | статуси донора, `followup_at` = +21 день після «📨 надіслано» |
| Реєстр для роботи в Excel | `data/donors.csv` (команда `donors`) |
| Сторінка реєстру | дашборд `/donors`, статичний сайт `docs/donors.html` |

### Команди

```bash
python -m grant_radar collect                    # зібрати новини всіма мовами
python -m grant_radar screen                     # розкласти по вкладках
python -m grant_radar donors                     # перебудувати реєстр донорів + CSV
python -m grant_radar letter --min-priority 4    # листи у data/letters/
python -m grant_radar letter --donor 31 --lang hu
python -m grant_radar contacts --min-priority 4  # пошук e-mail на сайтах донорів
python -m grant_radar export                     # статичний сайт + donors.html
python -m grant_radar serve                      # дашборд: / та /donors
```

У GitHub Actions кроки `donors` і `letter` виконуються щодня після збору новин,
тому реєстр і листи оновлюються самі.

### Що лишилося зробити людині

1. Заповнити `config/profile.yaml` → `community.contact` (ПІБ, посада, пошта,
   телефон) — інакше в листах стоятимуть заглушки `<ПІБ…>`.
2. Для донорів без розпізнаного імені («—») — відкрити новину за посиланням і
   вписати назву та сайт у реєстр; після цього `contacts` знайде пошту.
3. Надіслати листи й позначати статуси в `/donors`.
