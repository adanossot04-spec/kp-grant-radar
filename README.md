# 🛰️ Грант-радар: моніторинг грантів для комунальних і приватних підприємств

AI-агент, який **цілодобово моніторить грантові можливості та програми допомоги в ЄС і Україні**,
відбирає релевантні, **розділяє їх на «для комунальних» і «для приватних» підприємств** і
готує чернетки заявок, автоматично підставляючи дані вашої організації.

> **Працює виключно на безкоштовних API.** Жодної платної підписки: дані беруться з
> відкритих API ЄС і донорів (без ключів), AI-шар — з безкоштовних tier-ів Groq / Gemini /
> OpenRouter, автозапуск — GitHub Actions, хостинг — GitHub Pages.
> Повний каталог: **[docs/FREE-APIS.md](docs/FREE-APIS.md)**.

## Що робить агент

| Крок | Що відбувається |
|---|---|
| 1. Збір | 13 джерел: офіційні API ЄС (гранти + тендери), МФО, українські донори та міністерства |
| 2. Нормалізація | Єдина структура: назва, програма, статус, **дедлайн**, бюджет, посилання. Дедлайни витягуються навіть із тексту новин («до 15 листопада 2026», «deadline 30 November 2026») |
| 3. Скоринг | Бал 0–100 за профілем: тематика, гео-відповідність, ознаки конкурсу, мінус-слова, терміновість |
| 4. **Класифікація заявника** | 🏛 комунальні / ОМС · 🏭 приватний бізнес · 🤝 обидва · ❔ уточнити |
| 5. AI-аналіз *(безкоштовний ключ)* | Резюме українською, перевірка прийнятності, наступні кроки |
| 6. Виведення | Дашборд з групуванням за типом заявника, статичний сайт, JSON API, Markdown-дайджест, Telegram |
| 7. **Чернетка заявки** | Агент бере досьє з `config/memory.yaml` і сам заповнює адмінчастину, бюджет, чеклісти, а з LLM — і змістовні розділи |

Зараз у базі після першого запуску: **~1040 можливостей**, з них для комунальних — 389,
для приватних — 542 (решта потребує уточнення типу заявника).

## Джерела (усі безкоштовні, 13 увімкнених)

**ЄС**
- **EU Funding & Tenders Portal (SEDIA API)** — усі гранти ЄС, ключ не потрібен
- **TED** — тендери та закупівлі ЄС (API без ключа) → переважно для бізнесу
- **Interreg NEXT HUSKROUA** — транскордонна програма для Закарпаття
- **Keep.eu**, **EUSDR / Danube Region**, **European Commission Press corner**

**МФО та міжнародні донори**
- **Світовий банк** (API без ключа), **NEFCO**, **EIB**

**Україна**
- **Громадський простір** (гранти + новини), **Фонд енергоефективності**, **Міндовкілля**

Ще ~20 безкоштовних джерел із посиланнями, готових до підключення (Prozorro, ReliefWeb,
CORDIS, IATI, Grants.gov, Дія.Бізнес, ГУРТ, DREAM, UNDP, ЄБРР…) — у
**[docs/FREE-APIS.md](docs/FREE-APIS.md)**.

Додати джерело — 6 рядків у `config/sources.yaml`, код чіпати не треба:

```yaml
  - id: my_source
    name: "Назва"
    type: rss                   # rss | sedia | ted | worldbank
    region: UA                  # EU | UA | INT
    enabled: true
    weight: 1.0
    beneficiary_hint: private   # необов'язково
    url: "https://example.org/feed/"
```

## Поділ «комунальні / приватні»

Кожна можливість класифікується за текстом умов (`src/grant_radar/classify.py`):

- 🏛 **communal** — municipality, local authority, public body, комунальне, громада, ОМС
- 🏭 **private** — SME, business, entrepreneur, МСП, ФОП, підприємці, стартап
- 🤝 **both** — «legal entities», консорціуми, public-private, обидва набори ознак
- ❔ **unknown** — прямих вказівок немає, потрібна перевірка людиною

Де видно поділ:
- **дашборд** — окремі секції з лічильниками + фільтр «тип заявника»;
- **статичний сайт** на GitHub Pages — те саме, працює без сервера;
- **дайджест** (Markdown / Telegram) — окремі розділи для кожного типу;
- **CLI**: `python -m grant_radar top --benef communal` / `--benef private`;
- **API**: `/api/opportunities?beneficiary=private`.

З LLM-ключем класифікація додатково уточнюється моделлю.

## Файл-пам'ять: `config/memory.yaml`

Розширене досьє організацій, з якого агент заповнює заявки. Підтримує **кілька організацій
одночасно** (наприклад, КП і приватне ТОВ) — агент сам обирає потрібну за типом гранту.

Що в ньому:

| Секція | Для чого в заявці |
|---|---|
| `identity` | назви UA/EN, ЄДРПОУ, КВЕД, засновник, форма власності |
| `contacts` | юридична адреса UA/EN, керівник, контактна особа проєкту, бухгалтер |
| `international_ids` | **PIC** порталу ЄС, LEI, UEI, UNGM — без них заявку в ЄС не подати |
| `banking` | IBAN UAH/EUR/USD, SWIFT, кореспондентський банк |
| `staff` | чисельність, ключові фахівці, англомовні працівники |
| `finance` | обороти за 3 роки, аудит, **спроможність співфінансування** |
| `assets` / `permits` | техніка, полігон, ділянки, ліцензія на поводження з відходами |
| `operations` | населення, тонни ТПВ/рік, % сортування, ключові проблеми |
| `experience` | попередні проєкти, донори, партнери, місто-побратим |
| `strategy` | стратегія громади, план управління відходами, SECAP, SDG |
| `project_pipeline` | готові ідеї проєктів — агент підбирає їх під конкурси |
| `boilerplate` | стандартні тексти UA/EN: опис, місія, гендерна політика, сталість |
| `documents` | де лежать статут, витяг з ЄДР, фінзвітність |
| `sme_status` *(для приватних)* | категорія МСП за ЄС, працівники, оборот, de minimis, UBO |

Перевірка заповненості:

```bash
python -m grant_radar memory
```

```
▌ kp (communal, активна) — заповнено 15% (26/178 полів)
    contacts             █·········  17%
    finance              ··········   6%
    ⚠️  критичні незаповнені поля: identity.edrpou, banking.iban_uah, …
```

> ⚠️ Файл містить персональні та банківські дані. Тримайте репозиторій **приватним**
> або додайте `config/memory.yaml` у `.gitignore` (заготовка вже є в кінці файлу).

## Чернетка заявки

```bash
python -m grant_radar draft --benef communal          # для найкращої можливості для КП
python -m grant_radar draft --uid <id> --org private  # конкретна можливість і організація
```

У `data/drafts/<id>-<назва>.md` з'явиться документ:

0. **Паспорт можливості** — донор, програма, дедлайн, бал, тип заявника, посилання
1. **Адміністративні дані** — 22+ поля заявки, заповнені з пам'яті; незаповнені позначені ⚠️
2. **Проєктна ідея** — найкращий збіг із вашого `project_pipeline`
3. **Змістовна частина** — з LLM: проблема, мета, заходи, результати з індикаторами,
   цільові групи, сталість, відповідність політикам ЄС, project summary (EN), ризики
4. **Бюджет** — скелет таблиці з вашою спроможністю співфінансування
5. **Пакет документів** — чеклист зі статусом кожного файлу
6. **Чекліст перед подачею**
7. **Що терміново додати в memory.yaml**

Те саме через API: `GET /api/draft/<uid>` (кнопка «📝 чернетка заявки» на кожній картці).

## Швидкий старт

```bash
pip install -r requirements.txt
export PYTHONPATH=src

python -m grant_radar sources                  # перелік джерел
python -m grant_radar collect                  # сканування + скоринг + класифікація
python -m grant_radar top -n 15 --benef communal
python -m grant_radar memory                   # заповненість досьє
python -m grant_radar draft --benef communal   # чернетка заявки
python -m grant_radar serve                    # дашборд на http://localhost:8000
```

Решта команд: `rescore` (перерахунок після правок профілю, без мережі),
`export` (статичний сайт у `docs/`), `digest --min-score 45` (Markdown + Telegram),
будь-яка команда з `--no-llm` — примусово без AI.

## Безкоштовний AI-шар

Досить **одного** ключа з безкоштовним tier. Агент сам визначає провайдера за змінними
оточення у такому порядку:

| Провайдер | Змінна | Де взяти безкоштовно |
|---|---|---|
| Groq *(рекомендовано)* | `GROQ_API_KEY` | https://console.groq.com/keys |
| Google Gemini | `GEMINI_API_KEY` | https://aistudio.google.com/apikey |
| OpenRouter (моделі `:free`) | `OPENROUTER_API_KEY` | https://openrouter.ai/keys |
| Cerebras | `CEREBRAS_API_KEY` | https://cloud.cerebras.ai/ |
| Mistral | `MISTRAL_API_KEY` | https://console.mistral.ai/ |
| Ollama (локально) | `OLLAMA_BASE_URL` | https://ollama.com/ |

Без жодного ключа агент повністю працездатний — просто без AI-резюме та без
згенерованої змістовної частини заявки.

За запуск LLM аналізує щонайбільше `llm_max_items` (типово 25) **нових** записів і ніколи
не аналізує той самий двічі, тому безкоштовних лімітів вистачає з запасом.

## Налаштування профілю (`config/profile.yaml`)

Тематичні групи та їхні бали: `waste` 30, `municipal` 25, `business` 22, `urban` 18,
`transport` 18, `recovery` 15, `cross_border` 12, `energy` 12, `water` 10.
Для водоканалу — підніміть `water`; для суто бізнесового моніторингу — `business`.

```
бал = (Σ балів тем × 1.0 за збіг у заголовку / 0.55 за збіг у тексті
       + гео + ознаки фінансування − мінус-слова
       + бонус за дедлайн ≤ 45 днів + бонус за відкритий конкурс)
      × вага джерела × scale
```

Запобіжник: якщо профільного слова немає **в заголовку**, запис не отримає «🔥 висока» —
так відсіюються оборонні та суто наукові конкурси ЄС, у тексті яких згадуються «cities»
і «Ukraine». З LLM підсумковий бал = 60 % правила + 40 % оцінка AI.

## Обмеження

- SEDIA і TED — публічні, але неофіційні API: якщо Комісія змінить формат, збирач треба
  оновити (по одному файлу на джерело).
- Частина українських сайтів (Мінрозвитку, ГУРТ, Дія.Бізнес) не має RSS або закрита
  Cloudflare — для них потрібен HTML-збирач.
- Класифікація заявника за ключовими словами дає ~85 % точності: **завжди перевіряйте
  умови прийнятності в офіційному документі конкурсу** перед подачею.
- Агент знаходить, ранжує і готує чернетки, але **не подає заявки** — фінальне рішення
  і підпис за людиною.

## 🎯 Напрями пошуку (треки)

Кожна можливість автоматично отримує **напрям** — за пріоритетом:
`♻️ Відходи → 🎓 Освіта → 🚌 Транспорт → 🌳 Благоустрій → 💧 Вода → ⚡ Енергоефективність → 🏭 Бізнес → 🏗 Відновлення → 📋 Інше`
(спершу перевіряється заголовок, потім текст).

У дашборді та на статичному сайті список **за замовчуванням згрупований за напрямами**,
причому **відходи та освіта йдуть першими** (`src/grant_radar/tracks.py` → `PRIORITY_VIEW`).
Перемикач «групувати за…» дозволяє згрупувати за типом заявника або показати єдиний список.

### 🚛 Бонус за техніку, контейнери й обладнання
Якщо з можливості видно, що за кошти можна **придбати контейнери, сміттєвози, спецтехніку,
транспорт чи обладнання**, запис отримує:
* бали групи `equipment` (20, профіль `config/profile.yaml`);
* додатковий бонус `scoring.equipment_bonus: 10` (×1.0 у заголовку, ×0.6 у тексті);
* бейдж **🚛 техніка / контейнери** і причину «🚛 можливе придбання техніки/контейнерів/обладнання».

Фільтр «лише з технікою» (`?equip=1`) показує тільки такі записи,
фільтр «Напрям» (`?track=waste`, `?track=education`) — конкретний напрям.

### 🎓 Освітній напрям
Окремі джерела й запити: Erasmus+ Україна (`erasmus_ua`), запити SEDIA
(vocational education and training, school education infrastructure, skills development local).
Загальні навчальні слова («capacity building», «тренінг», «digital skills») винесено
в групу `skills` — вони дають бали, але не роблять запис «освітнім»,
щоб напрям «Освіта» лишався чистим.

## 💶 Фільтр і сортування за бюджетом

Агент намагається визначити **орієнтовну суму фінансування на проєкт у євро**
(`src/grant_radar/budget.py`) і розкладає можливості за діапазонами:

| Діапазон | Позначка |
|---|---|
| до 100 000 € | `s` — 💶 до 100 тис. € |
| 100 000 – 500 000 € | `m` — 💶 100–500 тис. € |
| понад 500 000 € | `l` — 💶 понад 500 тис. € |
| суму не вказано | `unknown` |

Звідки береться сума:
* портал **EU Funding & Tenders** — поле `maxContribution` (максимальний внесок ЄС
  на один грант); якщо його немає — річний бюджет теми / очікувану кількість грантів;
* **Світовий банк** — сума проєкту в USD (перераховується в євро);
* решта джерел — розпізнавання сум у тексті: `€250 000`, `EUR 1.5 million`,
  `до 500 тис. євро`, `2 000 000 грн`, `50,000 USD` тощо.
  Гривні/долари/злоті перераховуються за приблизними курсами (`budget.RATES`),
  роки на кшталт «2027 European…» відсікаються.

У дашборді та на статичному сайті з'явилися:
* селект **«будь-який бюджет / до 100 тис. / 100–500 тис. / понад 500 тис. / суму не вказано»**;
* сортування **«за бюджетом ↓»** і **«за бюджетом ↑»** (записи без суми — у кінці);
* бейдж на картці, напр. **💶 9,5 млн €**;
* сума в дайджесті `data/digest.md`.

API: `/api/opportunities?budget=m&order=budget&limit=50`.
Межі діапазонів змінюються константами `SMALL_MAX` / `MID_MAX` у `src/grant_radar/budget.py`.
